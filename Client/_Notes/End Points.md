/api/recipes - GET
- Returns all recipes

/api/recipes - PUT
- Creates a new recipe

/api/recipes/{ID} - GET
- Returns a specific recipe
  
/api/recipes/{ID} - PUT
- Updates a specific recipe
  
/api/recipes/{ID}/tags - GET
- Gets the tags for a specific recipe
  
/api/recipes/{RID}/tags/{ID} - GET
- Gets a specific Tag for a specific recipe

*New End points*
/api/recipes/collections - GET : Returns all collections
/api/recipes/collections - PUT : Create a collection
/api/recipes/collections/{ID} - GET : Returns all recipes within collection
/api/recipes/collections/{ID} - PUT : Add a recipe to collection
/api/recipes/collections/{CID}/{ID} - GET : Get the specific recipe
